# 钢铁洪流 · Tank Battle

一个用纯 HTML + Canvas + JavaScript 编写的原创坦克对战小游戏，单文件即可运行，无需任何依赖或构建步骤。

## 玩法

- 驾驶你的坦克守住基地，消灭每一波来犯的敌方坦克
- 共 **8 个波次**，敌人会越来越强、越来越快、装甲越来越厚
- 基地被摧毁即游戏结束；守住全部波次即可获胜

### 操作

| 按键 | 功能 |
| --- | --- |
| `W` / `↑` | 向上移动 |
| `S` / `↓` | 向下移动 |
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `空格` | 射击 |
| `P` | 暂停 / 继续 |

> 触屏设备会自动显示虚拟方向键和射击按钮。

## 地图元素

| 元素 | 说明 |
| --- | --- |
| 🧱 砖墙 | 可被子弹摧毁 |
| ⛓ 钢墙 | 不可摧毁 |
| 🌲 树林 | 可通行，但会遮挡坦克 |
| 🌊 水域 | 不可通行，子弹会没入水中 |
| 🚩 基地 | 必须守护的目标 |

## 运行

直接用浏览器打开 `index.html` 即可，或者本地起一个静态服务器：

```bash
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 特性

- 纯 Canvas 渲染，原创坦克/地图绘制
- 三种敌人（普通 / 快速 / 重甲）
- 每波随机化地图砖块布局
- Web Audio 合成音效（射击、爆炸、胜利等）
- 粒子爆炸特效与屏幕震动
- 键盘 + 触屏双操控
